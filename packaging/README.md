# ds-pet · Windows 桌面宠物

一只住在你桌面上的小宠物：会呼吸、发呆、打瞌睡、玩魔方、吃火锅，会跟着你的鼠标转头，
会被你拖着甩出去再弹回来。也可以让它跟着 AI 干活的进度说话——开始处理、这一轮完成、
出错、需要你确认，都会用气泡告诉你。

本仓库提供的是它的 **Windows 安装包**。

---

## 下载与安装

1. 下载 `ds-pet-setup-0.3.8.exe`；
2. 双击运行（文件较大，首次启动需要等几秒）；
3. 按向导点「下一步」：选择安装位置 → 勾选想要的附加项 → 安装 → 完成。

安装过程不会申请管理员权限（默认装在当前用户目录），不写系统目录，不装任何捆绑软件。

**系统要求**：Windows 10 / 11（64 位）

## 卸载

任选其一：

- 开始菜单 → ds-pet → **卸载 ds-pet**；
- Windows 设置 → 应用 → 已安装的应用 → ds-pet → 卸载。

## 使用

安装完成后，宠物会出现在桌面上；托盘区有图标，右键宠物或托盘图标都能打开菜单。

| 操作 | 效果 |
| --- | --- |
| 左键点它 | 有反应（Q 弹、说话、换表情） |
| 按住拖动 | 拖着走；松手太快它会飞出去撞墙弹回来 |
| 右键 | 对话 / 动作 ▸ / 碎碎念 / 查看余额 / 设置 / 重载配置 / 回到初始位置 / 关闭程序 |
| 双击托盘图标 | 重新叫出宠物 |

**主要功能**

- 一百余个透明动画，随机播放、无缝衔接；
- 随机左右转向、屏幕漫游，可以固定在原地不自己乱走；
- 多只宠物同屏，各自独立的开关、大小、位置；
- 可以自己写人设，让它用你喜欢的语气说话；
- 跟随 DSH 会话进度：开始处理 / 这一轮完成 / 出错 / 等待确认，配对应图标；
- 碎碎念、余额气泡、节日彩蛋；
- 可选开机自启、系统托盘常驻。

设置窗口里每一项都有说明，改完点「保存并应用」即生效。

## 给开发者

安装包由 Inno Setup 6 构建，相关脚本与素材都在本目录：

```
packaging/
├─ installer/          Inno 脚本（ds-pet.iss）、中文语言层、页面文案（pages.json）
├─ scripts/            素材生成脚本（一键画出所有界面底图与图标）
├─ assets/             生成的图片素材（由脚本产出，勿手改）
├─ electron-builder.yml  exe 打包配置
└─ dist-installer/     安装包输出目录
```

三步构建：

```powershell
# 1. 打包应用本体（产出 dsh-pet/dist-app/win-unpacked）
cd dsh-pet
npm run dist

# 2. 生成安装程序素材（改过文案或配色才需要）
cd ..
powershell -NoProfile -ExecutionPolicy Bypass -File packaging\scripts\build-installer-assets.ps1

# 3. 编译安装包（产物输出到桌面）
& 'D:\Application\Inno Setup 6\ISCC.exe' 'packaging\installer\ds-pet.iss'
```

界面文字全部绘制在背景图上，因此调整文案只需修改 `packaging/installer/pages.json`
再执行第 2、3 步，不需要改脚本。
